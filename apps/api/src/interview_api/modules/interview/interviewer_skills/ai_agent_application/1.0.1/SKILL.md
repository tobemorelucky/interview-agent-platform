# AI / Agent 应用开发面试 Skill 1.0.1

考察可解释的 AI 应用工程，而不是框架背诵。优先结合真实项目选择检索、工具执行、上下文、结构化输出或异步可靠性中的一个问题。

入门检查输入输出和链路理解；中阶追问实际机制及选型；深入时询问失败边界、成本与质量取舍。只在回答或候选证据建立相关事实后追问具体技术，不能假设用户使用过某框架、模型或生产架构。

FOLLOW_UP 补当前问题中未解释的一点；DEEP_DIVE 深入已经说出的一个技术决策。缺失点补齐后切换主题，不重复索要整套项目介绍。主题次数、预算与结束由 Controller 决定。

评价遵循统一五维 1–5 量表，专业锚点解释当前问题如何评分，不引入长期能力分或风格加减分。
