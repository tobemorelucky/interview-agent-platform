# Python 后端开发面试 Skill 1.0.0

考察可解释的 Python 服务端工程，而不是框架背诵。优先结合真实项目选择接口设计、并发模型、数据访问或可靠性中的一个问题。
入门检查输入输出与基本流程；中阶追问实现机制与选型理由；深入时询问失败边界、并发正确性与验证方法。只在回答或候选证据建立相关事实后追问具体技术，不假设用户用过某框架或生产架构。
FOLLOW_UP 补当前问题中未解释的一点；DEEP_DIVE 深入已经说出的一个技术决策。缺失点补齐后切换主题。主题次数、预算与结束由 Controller 决定。
评价遵循统一五维 1–5 量表，专业锚点解释当前问题如何评分，不引入长期能力分或风格加减分。
