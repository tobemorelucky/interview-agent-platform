# DEMO sample 简历与知识材料

本目录只用于 Parser / RAG 手工演示，不是用户真实简历或真实求职记录。

F4 来源核对：PDF 的原始 metadata 明确为 `Synthetic Candidate`、
`ChatGPT generated synthetic resume sample`；DOCX 同属既有 sample 提交，
使用 `.test@example.com` 测试邮箱、`demo-*` GitHub 标识、构造的联系方式，
metadata 作者为 `python-docx`，没有个人作者、批注或真实附件来源。
TXT 正文明确标记“测试简历”。两份二进制文件保留原貌，不冒充真实用户数据。

- `resume_backend_ai_rag.pdf`：DEMO 合成 PDF sample。
- `resume_agent_rag_backend.docx`：DEMO 构造 DOCX sample。
- `resume_rag_backend_plain.txt`：DEMO 构造 TXT sample。
- 其余知识材料也是 sample，不声明项目成绩或公司信息为真实事实。

文件中的人名、联系方式、教育和公司描述只能解释为演示角色与案例，
不得联系其中号码或将案例用于候选人能力认证。不要将个人上传文件放入本目录。
