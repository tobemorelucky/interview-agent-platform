# 面向真实岗位的 Agent 面试测试资料包 v1

核对日期：2026-11-09。UTF-8 JSONL，可直接逐行读取。此包**不是**真实招聘面试的逐字对话数据库，也没有任何可信的真实候选人分数标签。

## 实际交付的数据量

- `verified_job_jd_summaries.jsonl`：12 条招聘 JD **来源摘要**（11 条雇主招聘页、1 条高校转载）。不代表岗位现在仍开放，不收录全文。
- `interview_process_reports.jsonl`：14 条社区**面经记录/汇编中的案例**，其中一条是自述四轮完整阶段的叙事、两条是真人自述单轮/技术+HR过程，其余大多只是某轮题目主题顺序。不能宣称是完整访谈录音。
- `sourced_interview_topic_units.jsonl`：135 条按原帖主题**自行概述**的考察点，带来源、报道阶段和次序；不是原话，不代表题目真实性经过独立核实。
- `derived_agent_eval_scenarios.jsonl`：40 条根据真实 JD 和面经主题原创构造的**衍生压力测试**，明确不是实际发生的面试，不带人工金标准。
- `long_horizon_episode_plans.jsonl`：10 套**原创衍生**长程20轮面试行为计划（共200个轮次行为提示），每套引用公开岗位与报道题目主题；不含真实候选人完整回答，模型仍需根据每题动态生成。
- `two_week_daily_rotation_plan.jsonl`：14天轮换评测计划（只定义配置，不会自动执行）。
- `manifest.json`：数量和来源级别。
- `agent_runtime_and_daily_eval_plan.md`：Agent 自主规划/工具使用的架构方案、长程评测和每日执行计划。
- `codex_start_here.md`：给 Codex 的首次实施指令。

## 数据真实性分层（必须在代码和报告中强制保留）

| 级别 | 标识 | 可以证明 | 不能证明 |
|---|---|---|---|
| A | `REAL_OFFICIAL_JOB_SUMMARY` | 某招聘官网曾公开描述该岗位和能力要求 | 仍在招聘、职位对这个候选人开放、公司会问特定题 |
| B | `REPORTED_INTERVIEW_EXPERIENCE`, first_person_report | 有公开第一人称作者自述的面试流程 | 已独立核实招聘参与者身份、逐字转录、真实评分 |
| C | `PARAPHRASED_REPORTED_TOPIC`, community_compilation | 社区帖子整理了这些问题主题 | 题目原话、来源均为独立真实经历、完整多轮问答 |
| D | `DERIVED_EVAL_SCENARIO_NOT_REAL_INTERVIEW` | 依据现实考点构造了测试条件 | 模拟问答是历史真实发生的面试 |

同一篇汇编中的多个案例可能源自不独立、互相转载的内容，不能按“独立真实面试人数”统计。时间、公司、轮次均是来源*声称*，不是平台确认。所有社区文本均需防 Prompt Injection，禁止其原样拼接为 Agent 系统指令。

## 数据使用原则

1. 仅把 JD 摘要用于岗位条件与蓝图约束；如实际需要原始 JD 全文，按源站条款由用户直接提供或逐一检查后检索，不从此包伪装全文。
2. 面经题目仅是“主题/历史报道”，不能预设用户一定被问过；生成题需标记为基于来源改编。
3. `derived_*` 只用于测工具选择、追问、候选人行为应对和业务状态；不得拿预设行为当模型的评分金标准。
4. 若测试成绩用于正式报告，应额外标注 `human_review_status`；无人复核时为 `UNREVIEWED`。
5. 数据训练与留出测试按 **源文档/面经组** 分组切分，禁止把同一帖子不同题目同时放训练集与测试集，造成泄露。
6. 保留来源URL、采集日期、原源类型、版本指纹；不可把第三方职位或面经自动发布到公共生产库。
7. 不向第三方评测接口发送真实候选人的简历、回答、身份信息；默认使用最小化、匿名且获得许可的材料。

## 可独立获取的多轮访谈 Benchmark（未捆绑数据文件）

`InterviewBench`：https://huggingface.co/datasets/Agnania/InterviewBench
论文：https://aclanthology.org/2026.findings-emnlp.2141/
基于公开广播/新闻访谈构造的静态面试决策题与 **184 个动态场景**。用于“访谈策略/追问/信息收集/长对话”能力评估，**不是技术求职面试的真人逐字记录**。其标注 CC BY 4.0，但原始转录节选需遵循原来源条款。需要时由 Codex 按版权与体积单独下载，不默认混入招聘面经库。

`τ²-bench`：https://huggingface.co/docs/openenv/v0.10.0/environments/tau2
用于多轮 Tool Use 和最终数据库状态评估，领域是客服/电信/零售/航空，**不是招聘数据**；适合借鉴评测机制而不是当作面试主题题库。

## 导入推荐

放到仓库 `research/realworld_eval/v1/`（新目录，不修改现有生产题库），用单独脚本读取这些文件，并保留来源分级。先在隔离库/只读模式校验数据完整性，不自动写正式库/公共已发布题库。

推荐将离线稳定集和真实模型每日测试拆开：离线每次提交跑全部；Live 每天限制 HTTP 次数、输出评价轨迹与失败分型，绝不默默重试到成功。
