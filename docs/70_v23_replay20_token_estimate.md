# V2.3：20 轮离线 Replay 与 Token 预算

2026-11-09。**本轮外部模型请求 0。** 下文的历史 usage 是既有账本，不是本轮实测；新跑的业务结果均为 **REPLAY**，成本均为 **ESTIMATED**。

## 结论

这组固定、合法的 AI 应用开发场景，**20 轮中性估算 251,982 Token**：面试会话 226,112，终局 Coach 25,870。低至高情景为 **208,726–333,142**，是规划区间，不是统计置信区间。较 docs/63 的 357,080 中性预测低 105,098（29.43%），不是模型实测降耗：此前用早期调用均值与线性增长假设外推；本轮用真实业务组装的逐请求输入，并测量 Coach 和修复的实际消息结构。两批题目、快照和输出长度也不同。

**20 轮合法 Replay 走完了 Coach 和下一场 MemoryGuidedPlan；原 Live 失败仍能复现。** 不等于当前生产模型能稳定跑完 20 轮，也不代表 gap 冲突已修复。

## 2. 真实业务入口与外网阻断

- 只启动经核对的原 PostgreSQL 容器及其原卷，未重建或迁移。仅在已有 `interview_agent_v232_reliability_20261029_a` 测试库（0026）创建新合成用户、岗位、面试及后续快照；不写正式库或历史 Live Session。
- 测试进程先安装出站审计，应用仅可连接本机 PostgreSQL 5432。外部域名解析与外部 IP 连接自检均在请求发出前被拒。禁用 subprocess 网络逃逸路径，兼容 Live Provider 的调用入口另行硬拒绝；Main、Evaluation、Coach 只注入 Replay。未修改 `.env`、密钥、模型路由或任何生产代码。
- 用真实 service、原 Controller、Context Projection、Prompt Builder 和 PostgreSQL，独立创建 20 与 15 题两场。每次在模型边界保存完整 System/User 消息、wire SHA256、服务端 AgentRun input hash（Coach 是既有评价指纹）、版本、候选数量、知识观察、当前 gap、父问答长度及输入块大小。Evaluation 不投影全场候选和观察；对应字段为空，另记服务端已有观察数量。
- 先将 docs/69 的真实原输出送入固定 Replay 和生产业务校验：Schema 通过，仍报 `UNRESOLVED_KNOWLEDGE_GAP`。第二答只解决 RRF 公式与 k，另外两个旧 gap 尚存，旧契约拒绝目标整体充分展示。没有改原快照，也没有把失败结果计入新场有效评价。
- 合法场景使用独立的固定问答、评分与声明的 gap 解决结果；同一段程序在调用边界只选择真实提供的合法组合 ID，不替换 Controller。覆盖 RAG/RRF/重排、工具权限与幂等、状态与长期记忆、Kafka/offset、Redis 及恢复。Kafka 按现有 AI Skill 的系统设计场景考察，不新增 Kafka 独立目标。题源/答案不采用“Outbox 自动原子提交外部数据库和 Kafka 消费位点”的错误前提。

## 3. ESTIMATED 预算

### 增长与 200,000 上限

Main 的中性输入第 1 题 4,814 → 第 20 题 8,722；峰值 8,872。消息从 15,758 → 28,525 UTF-8 字节。第 1 到第 20 题，知识状态约增 9,466 字节，题目历史约增 3,655，主题覆盖约增 1,745；快照块仍约 4.3 kB，后段候选组合从 13 减至 2，抵消部分增长。Evaluation 中性输入 2,602–3,042，主要随本题、gap 与父问答波动；不会附带全场历史。终局 Coach 的 76,965 字节中，题目约 25.6 kB、评价约 21.0 kB，是另一处成本风险。

按当前会话准入公式，用估算已结算 usage 加**真实 Replay 输入结构对应的**下一次请求保守预留（投影/System/Schema 字节 + 两次最大输出及缓冲），在 20 轮路径上的首次拦截：

这不是运行中修改预算或强制终止的试验。Controller 可能根据同次请求的预算、题量或状态合法提前结束。高档模拟会话峰值（已用加下一请求预留）约 312,534。若将来重新评审预算，对同体量的 20 轮建议 **350,000 会话额度、约 400,000 整批规划额度**（含独立 Coach 与缓冲），不保证更大快照或更长生成可完成。此处不包含历史业务故障的重复重跑，也不是实际模型调用授权；优先解决 gap 契约后再谈 Live。
