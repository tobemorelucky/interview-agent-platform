1. 第 9 答后的 Main 选择合法 Agent 组合，却被 `ADAPTIVE_TOPIC_MISMATCH` 拒绝。“工具工作流”和“执行工具”未命中旧 Agent 词典，开头的“检索这块先聊到这”还会把题面归到冷却中的 RAG。修复在 `topics.py`，仅增加明确工具词汇和有界的句首收束识别。真正继续询问 RAG、带问号的前导句、背景限制和候选引用规则仍按原校验。以已收到的第 27 条真实响应做精确离线重放，复用原 Evaluation Run 19，Controller 提交第 9 条正式评价和第 10 题。新增模型 HTTP 与计费均为 0。
