# 10 管理后台设计

## 1. 后台目标

管理后台用于维护面经内容生产流水线。

核心对象：

- 采集任务
- Raw 内容
- Candidate 候选内容
- Published 正式面经
- 索引状态

---

# 2. 后台导航

建议：

```text
仪表盘
采集任务
候选审核
正式面经
失败任务
系统配置（后续）
```

---

# 3. 仪表盘

展示建议：

- 当前运行中任务数
- 今日发现内容数
- 今日候选数
- 今日发布数
- 最近失败任务
- 发布成功但索引失败数量

---

# 4. 采集任务管理

## 4.1 创建任务

字段：

- 任务名称
- 平台选择
- 关键词列表
- 每个平台最大采集量
- 图片下载
- 视频下载
- OCR 开关
- ASR 开关
- LLM 抽取开关
- 备注

## 4.2 任务列表

列：

- 任务名称
- 平台
- 状态
- 创建时间
- 创建人
- 发现数
- 成功抓取数
- 候选数
- 失败数

## 4.3 任务详情

内容：

- 配置快照
- 状态进度
- 每个 stage 数量
- 错误摘要
- 失败重试
- 关联 raw 内容数量
- 关联 candidate 数量

---

# 5. 候选审核

## 5.1 列表页

筛选：

- 平台
- 公司
- 岗位
- 评分区间
- 是否疑似营销
- 审核状态
- 发布时间

表格列：

- 标题
- 平台
- 公司 / 岗位
- 分数
- 审核状态
- 创建时间
- 操作

## 5.2 详情页

建议 Tab：

1. 概览
2. 原始内容
3. 解析文本
4. OCR / ASR
5. 结构化抽取
6. 评分解释
7. 去重信息
8. 审核操作

---

# 6. 审核操作

支持：

- 发布
- 拒绝
- 备注
- 重新评分
- 重新解析
- 查看原始来源

发布时需要确认：

- 是否进入正式面经库；
- 发布标题；
- 展示摘要是否允许编辑；
- 备注。

---

# 7. 正式面经管理

列表：

- 标题
- 公司 / 岗位
- 平台
- 可信度
- 发布状态
- 索引状态
- 发布时间

操作：

- 查看详情
- 下架
- 重新索引
- 查看来源候选

---

# 8. 失败任务页

展示：

- 任务 ID
- 来源平台
- 当前 stage
- 错误码
- 重试次数
- 最近错误
- 重试按钮

---

# 9. 权限

所有后台页面：

- 前端隐藏普通用户入口；
- 后端必须 Admin 权限验证；
- 不依赖前端权限作为唯一保护。

---

# 10. 管理后台 Phase 实施顺序

Phase 4：

- 创建采集任务
- 列表
- 详情

Phase 5：

- Candidate 审核
- 发布 / 拒绝
- 正式面经基本查看

Phase 6：

- OCR 展示

Phase 7：

- ASR / 视频信息展示

---

# 11. 后台验收

- 管理员可创建任务；
- 可查看任务状态；
- 可看到候选内容；
- 可发布；
- 可拒绝；
- 发布内容进入用户可查库；
- 索引状态可见；
- 普通用户不可访问后台 API。
