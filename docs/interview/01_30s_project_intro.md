# 30 秒项目介绍

> 这是一个面向秋招的多 Agent 求职与模拟面试平台。用户上传简历后，系统先建立有证据支撑的候选人画像，再匹配公开岗位，围绕项目和岗位要求开展面试、评价与复盘。我重点做的不是让模型包办流程，而是把事实、状态和计数交给程序：画像引用原始简历证据，面试上下文固定版本，模型只给评价和动作建议；长期记忆也必须经过用户确认。

这段适合按正常语速讲约 25～40 秒；请实际计时练习，不把时长当成已测指标。

## 接住追问的一句话

面试官问“哪里最有特点”，回答：

> 我把模型输出当成待验证的业务输入，而不是系统真相。比如画像不再让模型自由写事实，而是让它选证据，由程序建立可追溯的稳定事实。

面试官问“做到什么程度”，回答：

> 是个人项目，已经有本地完整链路、真实模型和真实资料验收，也保留 Replay 回归；不是生产规模上线项目。

## 表达边界

- 不说“六个 Agent 自主协商解决所有问题”，它们是有明确输入、输出和控制边界的角色。
- 不说“证据保证模型结论完全正确”，证据保证来源可查，仍需业务校验与人工确认。
- 不说“全链路公网实时搜索”，Live Search 已冻结，真实资料通过维护者人工来源导入。
- 当前默认模型是 Doubao 2.1 Turbo；历史 DeepSeek 验收、排障是不同阶段的真实记录。
