职位描述
1. 参与 AI Agent 平台及智能工作工具的建设，探索 AI 在游戏研发和日常工作中的应用；
2. 参与 Agent 工作流、上下文工程、知识检索、工具调用和自动化任务等能力的研发与优化；
3. 参与 Agent、Skill、插件及 AI 应用的接入、调试、发布和复用，推动优秀实践沉淀为标准化能力；
4. 推动 AI 能力与项目管理、文档、消息及研发工具等现有系统集成，融入真实业务流程；
5. 参与模型调用、运行追踪、效果评测和成本分析，持续提升 Agent 的稳定性、易用性和任务完成效果；
6. 跟进大模型、Agent 框架和 AI 编程工具等前沿技术，参与技术调研、原型验证与工程化落地；
7. 与产品、研发、TA、引擎、工具链等团队协作，理解实际问题并提供 AI Native 的解决方案。
职位要求
1. 本科及以上学历，计算机、软件工程、人工智能等相关专业优先；
2. 具备扎实的编程基础，熟悉 Go、Python等主流编程语言，具备良好的代码习惯和工程意识；
3. 了解数据结构、算法、操作系统、计算机网络、数据库等基础知识，能够理解并参与平台型系统的设计与开发；
4. 了解服务端开发基础，熟悉 HTTP/gRPC API、数据库、缓存、消息队列、任务调度、权限控制、日志监控等常见后端开发概念；有 Go 服务端开发经验优先；
5. 对大模型、AI Agent、开发者工具和智能工作流有浓厚兴趣，并有相关工具的实际使用经验；
6. 了解 Prompt Engineering、LLM API、RAG、Function Calling / Tool Use、Agent 工作流等基本概念；课程、实习或个人项目经验均可；
7. 具备较强的学习能力、问题拆解能力和动手能力，能够完成方案分析、原型开发和效果验证；
8. 具备良好的沟通协作能力，愿意深入游戏研发及不同业务流程理解真实需求，并推动 AI 能力在实际场景中落地。
加分项
1. 了解 Agent SDK、LangChain、AutoGen、MCP、RAG、上下文工程、Prompt 编排、多 Agent 协作或自动化工作流等相关技术者优先；
2. 了解 Agent 调试、运行追踪、效果评测、日志分析、Token 成本分析或可观测性建设者优先；
3. 对 AI Native 产品、人机协作方式、Agent 工作台形态或智能研发工具有自己的思考或实践。
