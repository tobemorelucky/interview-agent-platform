# 使用与评分约定

## 一、数据来源

3份公开面经均源自牛客用户公开自述（并非企业官方面试题库），本文件根据报告中的主题、题序重新组织为**3场可从开场到结束跑通的模拟面试**。不是逐字复写、不是完整真实录音、也没有原始真人评分。

## 二、怎么测试

- 数据库导入时从 `jd_50.jsonl` 使用 `company/position/jd_text/source_url`，按真实职位名称/业务内容生成面试上下文，不要让模型看到隐藏 `key_points`。
- `interviews_3.json` / `interview_questions_3.jsonl` 中的 `questions` 是测试脚本；评分要点和 red_flag 是评估器用的隐藏答案，不属于JD原文。
- `synthetic_answer_testcases.jsonl` 按 `case_id + variant + question_id` 对齐，共 strong/blank/incorrect 三类合成候选人，能用同一个面试流程测试评分是否合理。
- `expected_band` 是软件测试区间，不是基于真人答案的金标。不能强求模型每题都精确命中区间；对未答出内容误判覆盖、明显错误给满分才属于严重质量问题。
- 样本中有些回答故意使用简短模板，目的是让评分脚本易于回归；不是自然面试水平测量。

## 三、验收

1. 所有50条拥有非空职位、公司、至少2条职责、至少3条要求和可打开来源URL；原始职位可能已关闭招聘，不应宣称均在招。
2. 3场有顺序题目、场次信息、评分点与失败红线，并可生成完整报告。
3. 使用合成答案并审计评价：评分引用必须是该回答子串，不将答案写进被测试模型上下文；空白回答不该得到高分；技术错误不能被当正确。
4. 最后用户上传自己真实简历（建议脱敏），使用独立账号或清空的隔离测试用户状态完整体验一次。
