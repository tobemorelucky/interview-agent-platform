工作内容
- 基于嵌入式平台，负责 AI Agent 智能体在车端场景的运行时基座软件开发；
- 参与 Agent 运行时的设计与开发（模型调度、工具调用框架、上下文管理、多 Agent 协同调度等）；
- 开展 Agent 运行时的性能优化与稳定性建设；
- 参与 Agent 基座与车端操作系统、推理引擎、感知系统的集成；
- 与算法、产品、系统架构团队协作，推动 Agent 运行时基座在多平台、多车型上的复用与演进；
- 跟踪 Agent 框架、端侧大模型运行时、Agent 系统软件等前沿技术。
任职要求
- 全日制本科及以上学历，计算机、软件工程、人工智能、电子信息等相关专业；
- 扎实的计算机基础，至少熟练掌握一门主流编程语言（C / C++ / Python 等），熟悉至少一种嵌入式操作系统（Linux、FreeRTOS、Sel4等）；
- 熟悉主流大模型的基本原理与调用方式，了解 Function Calling、Agent 编排、工具调用等关键技术；
- 了解 LangChain、AutoGen、Dify 等 Agent 框架，或有端侧 Agent 运行时开发经验者优先；
- 具备较强的学习能力、自驱力和团队协作意识，对智能汽车行业有浓厚兴趣者优先。
